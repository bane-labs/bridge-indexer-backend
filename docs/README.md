# Documentation

This directory contains project documentation.

## Lifecycle semantics

The [settlement and execution specification](operation-lifecycle.md) defines the agreed operation model, chain-event mapping, API compatibility, frontend presentation, and historical recovery requirements. The [domain glossary](../CONTEXT.md) defines the corresponding terminology.

## Structure

Please add documentation files to this directory as needed:

- **API Specification** - Document REST API endpoints and request/response schemas
- **Deployment Guide** - Document deployment procedures and environment setup
- **Architecture Documentation** - Document system design and component interactions
- **Development Guide** - Document development setup and contribution guidelines
- **Troubleshooting Guide** - Document common issues and solutions

## Format

Use Markdown format for documentation files and follow these conventions:

- Use descriptive file names (e.g., `api-specification.md`, `deployment-guide.md`)
- Include clear section headers and table of contents for longer documents
- Always add an empty line before code blocks
- Specify language for code blocks (e.g., `json`, `bash`, `go`)
